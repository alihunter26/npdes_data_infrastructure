Data Documentation

A file-by-file reference for the raw EPA source data behind this site: what each table contains, its key variables, row counts, and how the tables join together. For which years each date/year variable actually has data, see Temporal Coverage.

Key Fields & Joins

Key field columns are present in all CSV files and may be used to join and relate data between files. The following table describes how the tables may be joined:

#Key Field(s)Tables
1 NPDES_ID or EXTERNAL_PERMIT_NMBR All tables (except violation enforcement)
2 REGISTRY_ID or FACILITY_UIN ICIS_FACILITIES, NPDES_INSPECTIONS, NPDES_INFORMAL_ENFORCEMENT_ACTIONS
3 NPDES_VIOLATION_ID {NPDES_PS_VIOLATIONS, NPDES_CS_VIOLATIONS, NPDES_SE_VIOLATIONS, NPDES_EFF_VIOLATIONS}*, NPDES_VIOLATION_ENFORCEMENTS
4 VERSION_NMBR ICIS_PERMITS, NPDES_EFF_VIOLATIONS
NPDES ID — EPA's internal ID number, at the permit level.
External Permit Number — assigned by the state agency; format varies by state and can change over time or across permit numbers.

ICIS-NPDES — ICIS-Water Datasets

ICIS_FACILITIES.csv

1.19M rows

Facility/source-level identifying data. Contains basic information about every regulated facility, including its name, location, and whether it discharges into impaired waters.

Key Variables: NPDES_ID FACILITY_NAME STATE_CODE CITY GEOCODE_LATITUDE/LONGITUDE IMPAIRED_WATERS

Notes: missing values in county code, latitude, and longitude.

ICIS_PERMITS.csv

1.69M rows

Permits. Contains detailed information about each permit, including its status, flow levels, the water body it affects, and all relevant dates.

Key Variables: EXTERNAL_PERMIT_NMBR PERMIT_STATUS_CODE MAJOR_MINOR_STATUS_FLAG EXPIRATION_DATE STATE_WATER_BODY_NAME TOTAL_DESIGN_FLOW_NMBR

Notes: missing values for total design flow (only collected for large facilities treating a measurable, continuous body of water). High NA rate is because they're not applicable, not because they're missing.

NPDES_CS_VIOLATIONS.csv

81K rows

Compliance schedule violations. Records instances where a facility failed to meet a deadline outlined in its compliance schedule.

Key Variables: NPDES_ID VIOLATION_DESC SCHEDULE_DATE ACTUAL_DATE RNC_RESOLUTION_DATE

Notes: NaN resolution code means it's still in progress.

NPDES_DATA_GROUPS.csv

1.18M rows

Data groups. Categorizes permits into data groups, which is useful for filtering and organizing permit types — the map of the database. Refer to it before downloading and merging ICIS tables to make sure you're pulling the right data for your research question.

Key Variables: EXTERNAL_PERMIT_NMBR NPDES_DATA_GROUP_CODE NPDES_DATA_GROUP_DESC

NPDES_FORMAL_ENFORCEMENT_ACTIONS.csv

111K rows

Formal enforcement actions. Records serious legal actions taken against facilities, such as court orders and financial penalties.

Key Variables: NPDES_ID ENF_TYPE_DESC AGENCY FED_PENALTY_ASSESSED_AMT STATE_LOCAL_PENALTY_AMT

Notes: EPA and state level; most actions are not penalty-bearing, especially most don't have federal and state penalties.

NPDES_INFORMAL_ENFORCEMENT_ACTIONS.csv

821K rows

Informal enforcement actions. Records lower-level enforcement actions, such as warning letters and notices of violation.

Key Variables: NPDES_ID ENF_TYPE_DESC AGENCY ACHIEVED_DATE OFFICIAL_FLG

NPDES_INSPECTIONS.csv

1.89M rows

Inspections. Logs all facility inspections, including who conducted the inspection and what the outcome was.

Key Variables: NPDES_ID COMP_MONITOR_TYPE_DESC STATE_EPA_FLAG ACTUAL_BEGIN_DATE ACTIVITY_OUTCOME_DESC

Notes: many missing end date (still ongoing).

NPDES_NAICS.csv

318K rows

NAICS industry type. Links each permit to its industry type using the modern NAICS classification system.

Key Variables: NPDES_ID NAICS_CODE NAICS_DESC PRIMARY_INDICATOR_FLAG

NPDES_PERM_COMPONENTS.csv

757K rows

Permit components. Describes the individual components that make up each permit.

Key Variables: EXTERNAL_PERMIT_NMBR COMPONENT_TYPE_CODE COMPONENT_TYPE_DESC

NPDES_PERM_FEATURE_COORDS.csv

628K rows

Permit feature coordinates. Provides geographic coordinates for specific permit features, such as discharge outfall points.

Key Variables: EXTERNAL_PERMIT_NMBR PERM_FEATURE_NMBR LATITUDE_MEASURE LONGITUDE_MEASURE

NPDES_PS_VIOLATIONS.csv

395K rows

Permit schedule violations. Records instances where a facility failed to meet a milestone outlined in its permit schedule.

Key Variables: NPDES_ID VIOLATION_DESC SCHEDULE_DATE RNC_DETECTION_DATE RNC_RESOLUTION_DATE

NPDES_QNCR_HISTORY.csv

7.87M rows

Quarterly noncompliance records. Contains quarterly noncompliance records for each facility over time, making it the best dataset for identifying trends.

Key Variables: NPDES_ID YEARQTR HLRNC NUME90Q NUMCVDT NUMSVCD

NPDES_SE_VIOLATIONS.csv

329K rows

Schedule event violations. Records individual violation events, such as spills or bypasses, and includes a free-text comment field for additional detail.

Key Variables: NPDES_ID VIOLATION_DESC SINGLE_EVENT_VIOLATION_DATE SINGLE_EVENT_VIOLATION_COMMENT

NPDES_SICS.csv

785K rows

SICS industry type. Links each permit to its industry type using the older SIC classification system.

Key Variables: NPDES_ID SIC_CODE SIC_DESC PRIMARY_INDICATOR_FLAG

NPDES_VIOLATION_ENFORCEMENTS.csv

4.91M rows

Violation enforcement. Connects violation records to enforcement actions, serving as the key linking table between those two datasets.

Key Variables: NPDES_VIOLATION_ID VIOLATION_DESC ACTIVITY_TYPE_DESC ENF_IDENTIFIER

Notes: does not contain NPDES_ID or EXTERNAL_PERMIT_NMBR; join with individual violation files through NPDES_VIOLATION_ID to uncover NPDES_ID.

Other NPDES Datasets

NPDES_DMRS_FY2025.csv

26.9M rows

DMR data. Every self-reported discharge measurement in fiscal year 2025, each paired with the permit limit it's measured against. One row per pollutant, per discharge point, per monitoring period.

Key Variables: EXTERNAL_PERMIT_NMBR PERM_FEATURE_NMBR PARAMETER_DESC LIMIT_VALUE_NMBR DMR_VALUE_NMBR MONITORING_PERIOD_END_DATE

Notes: limit and reported value sit side by side, so exceedances can be computed directly. No facility names/locations or industry type. FY2025 only.

NPDES_LIMITS.csv

17.1M rows

Permit limits. The numeric discharge limits written into each permit. One row per limit — one pollutant, at one discharge point, under one permit, during one time period.

Key Variables: EXTERNAL_PERMIT_NMBR PERM_FEATURE_NMBR PARAMETER_DESC LIMIT_VALUE_NMBR / LIMIT_UNIT_DESC STATISTICAL_BASE_CODE (daily max vs. monthly avg) LIMIT_BEGIN_DATE / LIMIT_END_DATE

Notes: includes seasonal applicability by month (JAN–DEC columns). No reported discharge — pair with DMR for actual-vs-allowed.

npdes_outfalls_layer.csv

819K rows

Discharge points. A pre-joined, analysis-ready spatial layer combining facility info, permit details, compliance status, and coordinates into one flat table. One row per permitted discharge point (outfall).

Key Variables: EXTERNAL_PERMIT_NMBR PERM_FEATURE_NMBR FACILITY_NAME LATITUDE83 / LONGITUDE83 MAJOR_MINOR_FLAG CWP_CURRENT_SNC_STATUS

Notes: coordinates are per discharge point, not facility. Snapshot at time of download — no dates, not time-series. Little violation/water-quality detail.

NPDES_CATCHMENTS.csv

1.25M rows

Catchment index — permits to catchments. Links each permitted discharger to the NHDPlus catchment and HUC-12 watershed it sits in — the spatial crosswalk from permits to the hydrologic network.

Key Variables: NPDES_ID NHDPLUSID WBD_HU12 / WBD_HU12NAME REACHCODE LATITUDE83 / LONGITUDE83

Notes: join key to ATTAINS water-body assessments via NHDPLUSID.

NPDES_ATTAINS_AU_SUMMARIES.csv

813K rows

Catchment index — ATTAINS AU summaries. Links dischargers to the condition of their receiving waters, summarizing each assessment unit's impairment status and designated-use support under ATTAINS.

Key Variables: NPDES_ID ASSESSMENTUNITIDENTIFIER WATER_CONDITION CAUSE_GROUPS_IMPAIRED E90_POT_IMP_PARAMETERS designated-use flags (DRINKINGWATER_USE, RECREATION_USE, …)

Notes: E90_POT_IMP_PARAMETERS ties measured exceedances to impairment causes. Joins to permits via NPDES_ID, to catchments via ASSESSMENTUNITIDENTIFIER.

ATTAINS_AU_CATCHMENTS.csv

0 rows

Catchment index — ATTAINS AU catchments. Intended as the crosswalk between ATTAINS assessment units and NHDPlus catchments (impairment status, TMDL flags, water-body geometry).

Key Variables: NHDPLUSID ASSESSMENTUNITIDENTIFIER OVERALLSTATUS / ISIMPAIRED ON303DLIST HASTMDL

Notes: empty file — header only, 0 data rows. The download appears to have failed and needs to be re-pulled.

ICIS_MASTER_GENERAL_PERMITS.csv

2.8K rows

Master general permits. Permits covering entire categories of similar facilities (e.g., stormwater, agricultural) rather than individual sites — facility type, permit, and issuing agency for each master general permit.

Key Variables: EXTERNAL_PERMIT_NMBR FACILITY_TYPE_INDICATOR MAJOR_MINOR_STATUS_FLAG ISSUING_AGENCY ISSUE_DATE / EXPIRATION_DATE

Notes: no geographic/location data or affected water bodies. Small reference table.
