Supplementary Brief

Row and Permit Attrition Across the DMR Filter Pipeline

FY2009 vs. FY2025: how many observations and distinct permits survive each step of the DMR filter pipeline.

Download PDF

Scope and Data

This brief tracks how many observations (DMR rows) and how many distinct permits survive each step of the DMR filter pipeline, comparing FY2009 against FY2025. The starting point (Stage 0) is the raw, completely unfiltered DMR file exactly as delivered by EPA ECHO — every permit (major and minor, individual and general), every parameter, feature type, and monitoring location, with no restriction of any kind. Four filtering stages are then applied in sequence, narrowing that raw universe down to a single pollutant/monitoring-location/limit-type slice used for TSS effluent compliance analysis:

  1. Major-Individual — restrict to permits that are individual (PERMIT_TYPE_CODE = "NPD") and were flagged major in at least one permit version. No parameter, feature-type, or monitoring-location restriction yet.
  2. +TSS (00530) — restrict to PARAMETER_CODE = '00530' (Total Suspended Solids).
  3. +Effluent Gross — restrict to MONITORING_LOCATION_CODE IN ('1','EG') (both map to "Effluent Gross" per EPA's REF_MONITORING_LOCATION table).
  4. +C1/Q1 — restrict to LIMIT_VALUE_TYPE_CODE IN ('C1','Q1') (the concentration- and mass-average value slots).

Each stage is built by fiscal-year-parameterized filter scripts and self-verifies column counts and category cardinality before writing its output. Stage 0's summary is computed directly via DuckDB SQL aggregation rather than loaded into R (the raw file is 11–27M rows, too large to safely read in full on this machine). All figures below are measured directly from the raw file and the four filtered CSVs for each fiscal year, not estimated.

Reproducibility

Each stage is built by dmr analysis/filter_dmr_*.R (parameterized by fiscal year); Stage 0 is computed by scripts/summary/build_dmr_raw_summary.R. See the full PDF for the citable, formally typeset version of this brief.
