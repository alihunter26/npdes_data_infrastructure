Temporal Coverage

Which years each date/year variable actually has data for, across every raw source file. Each row is one (file, variable) pair; each column is a year that appears in at least one file. A shaded cell shows the observation count for that year; darker shading means more observations relative to other years in that same row.

Only columns whose name contains DATE or YEAR are scanned. For DATE columns the year is taken from the last 4-digit run in the value (handles mm/dd/yyyy); for YEAR-named columns (e.g. YEARQTR), it's the first 4-digit run. No date parsing is done, so this is cheap to run even on multi-GB files.
Year columns are not filtered to a plausible range — implausible values (e.g. a year of "1" or "8202") are kept rather than silently dropped, so they show up here as genuine, if odd, data-quality signals rather than being hidden.
