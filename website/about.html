About & Methodology

Data Sources

The underlying data comes from EPA's public Clean Water Act compliance and monitoring systems: ICIS-NPDES (permits, facilities, violations, enforcement actions, and Discharge Monitoring Reports) and ATTAINS (state water quality assessments). Raw files are downloaded directly from EPA's public data distribution.

How These Summaries Are Built

Each dataset is processed by a registry-driven summary script that computes, per variable:

  • Percent of values missing
  • For categorical variables: the number of distinct categories and the top 5 most frequent values, with share and count
  • For numeric and date variables: minimum, 5th percentile, median, mean, 95th percentile, and maximum

These per-dataset summary tables are generated on a snapshot of the raw data and are not live-updated in real time; each dataset page notes its source file.

Interpreting the Tables

A high "% Missing" value means that variable was frequently blank or not reported in the underlying records — not necessarily an error. Some fields are intentionally optional depending on facility or permit type. The "Distinct Categories" / "Distinct Facilities" counts describe how many unique values exist across the entire dataset, while "top values" show only the five most common.
